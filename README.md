# Portfolio - Kareem Basem

A production-ready personal portfolio built to showcase projects, certifications, experience, and contact information with a modern responsive interface and smooth motion.

## Tech Stack

- React (Vite)
- Tailwind CSS
- Framer Motion

## Features

- Responsive design across mobile, tablet, and desktop
- Smooth animated interface using Framer Motion
- Projects showcase with previews and external links
- Certifications system with featured items and category filtering
- Experience section with structured timeline cards
- Contact section with direct professional links

## Sections Overview

- Hero
- About
- Skills
- Experience
- Projects
- Certifications
- Contact

## Getting Started

### Install dependencies

```bash
npm install
```

### Start development server

```bash
npm run dev
```

## Production Build

```bash
npm run build
```

### Preview production build locally

```bash
npm run preview
```

## Deployment

### Vercel

1. Push the project to GitHub.
2. Import the repository into Vercel.
3. Vercel should detect Vite automatically.
4. Confirm the build command is `npm run build`.
5. Confirm the output directory is `dist`.
6. Deploy.
